# Licensing and Product Boundary

Agent Replay's existing repository releases are Apache-2.0. Those grants remain valid for code distributed under that license.

This repository is the open forensic/interoperability line. New marketplace applications, user interfaces, hosted services, enterprise integrations, billing systems, and other separately distributed products are not automatically part of this repository or automatically Apache-2.0 merely because they interoperate with Agent Replay. Each such distribution must declare its own license and preserve licenses/notices for any Apache-2.0 or third-party material it actually contains.

Do not copy Apache-2.0 core source into a differently licensed product and remove the Apache obligations. Prefer a stable process/API/artifact boundary or otherwise perform a dependency/license review before distribution.

The AgenTrust integration is an interoperability relationship. Agent Replay's TRACE adapter depends optionally on the separately distributed AgenTrust verifier. AgenTrust verification of an integration does not transfer Agent Replay ownership, and Agent Replay must not imply broader AgenTrust certification than the reproduced integration/version/scope supports.

Product branding and trademarks are separate from source-code copyright licensing. See NOTICE and Apache-2.0 Section 6.

Before changing the license of this repository itself, accepting substantial third-party contributions under different terms, or combining code under another license into a commercial distribution, perform a dedicated provenance and compatibility review.

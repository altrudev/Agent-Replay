Agent Replay · incident report
Runs in your browser. Nothing is uploaded.

Drop an incident file here

or click to choose one

Make one from your agent's log with:

agent-replay reconstruct your-log.jsonl --json -o incident.json

or skip this page and run agent-replay reconstruct your-log.jsonl --html report.html

Before sharing: this page contains the full incident, including evidence values. To send it outside your team, run agent-replay export-share first.

This page only displays what Agent Replay reconstructed. Expected values come from the supplied evidence and are not independently verified.
